How these apps work

Everything you enter is stored in a database on your own device. There are no accounts to create, no analytics, no advertising identifiers and no third-party SDKs collecting anything. That is a deliberate constraint rather than a feature that has not been built yet: an app that makes no network requests cannot leak what it does not send.

The trade-off is honest and worth stating plainly — if you delete an app, its data goes with it, and there is no copy on a server for me to restore. Each app can export everything it holds to a file you keep yourself.
